# Frames & Feelings — PWA 1.0

Рабочее офлайн-first PWA на HTML/CSS/JavaScript, без платных зависимостей. Включает категории, записи, оценки 1–5, загрузку обложек с устройства или по URL, поиск записей, клетчатые страницы заметок, рисование, стикеры, локальный профиль и JSON резервное копирование.

## Как установить на iPhone

1. Разместите **всю папку** на HTTPS-хостинге, например GitHub Pages или Cloudflare Pages (бесплатные тарифы при соблюдении их условий). Простой просмотр HTML-файла через «Файлы» iPhone не обеспечивает установку PWA и Service Worker.
2. Откройте полученную HTTPS-ссылку в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить». На некоторых версиях iOS может понадобиться выбрать «Открывать как веб-приложение».

## Важно

- Аккаунтов, друзей и сервера пока нет: профиль локальный. Закрытый профиль — лишь настройка для будущей синхронизации, а не серверная защита.
- Данные хранятся в localStorage браузера; при очистке данных Safari они могут исчезнуть. Регулярно делайте резервную копию из раздела «Профиль».
- Большие фотографии сжимаются; размер локального хранилища ограничен. Рисунки сохраняются в рамках страницы.
- Google Images открывается во внешней вкладке, встроенного поиска пока нет.
- Для установки PWA нужен HTTPS и публикация файлов. Этот ZIP сам по себе не является ссылкой на опубликованное приложение.
